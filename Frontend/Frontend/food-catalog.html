Local nutrition setup

Food Catalog

Add the foods you cook or eat often so the intake page can calculate macros from your own database.

How to use it

Recommended entries

  • Use weight-based entries for foods like rice, oats, and flour.
  • Use quantity-based entries for foods like bananas, eggs, and fruits.
  • For weight-based foods, set serving size to 100 and use the macros per 100g.
  • For quantity-based foods, set serving size to 1 and use the macros per one item.
